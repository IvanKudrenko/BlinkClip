# BlinkClip

**Edit without editing.**

BlinkClip is a Mac app for batch video processing. It applies repetitive video tasks across multiple files without requiring a traditional timeline workflow.

[Website](https://blinkclip.baproj.com/) · [Download](https://blinkclip.baproj.com/download/) · [Demo](https://blinkclip.baproj.com/demo/) · [Documentation](https://blinkclip.baproj.com/docs/) · [Guides](https://blinkclip.baproj.com/guides/) · [Changelog](https://blinkclip.baproj.com/changelog/)

## What BlinkClip does

- Trim the same time range from multiple videos.
- Convert, compress, resize, or change the speed of a batch.
- Merge videos or add an intro to each file.
- Extract, mute, or add audio.
- Insert a clip or apply an overlay.
- Still Trim videos, Quick Crop them, or combine actions into reusable workflows.

BlinkClip 1.2 includes these actions: Trim, Convert, Compress, Resolution, Speed, Merge, Add Intro, Extract Audio, Mute, Add Audio, Insert Clip, Overlay, Still Trim, Quick Crop, and Workflow.

## How it works

1. Select videos or a folder.
2. Choose an action and configure it.
3. Apply it to the batch.
4. Process the files and review the finished videos.

## Requirements

- macOS 12.4 or later
- No separate FFmpeg installation required
